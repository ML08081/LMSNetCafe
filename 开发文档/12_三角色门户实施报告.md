# 三角色门户实施报告

报告日期：2026-08-31

## 1. 本轮结论

系统已由“同一套管理员页面按菜单隐藏”调整为三个相对独立、数据互通的角色门户。登录入口保持统一，登录后根据数据库角色和权限进入对应工作空间。

当前三个有效演示账号：

| 账号 | 密码 | 角色 | 登录后首页 |
| --- | --- | --- | --- |
| `admin` | `123456` | 超级管理员 | 经营管理控制台 |
| `cashier` | `123456` | 前台人员 | 门店运营工作台 |
| `member001` | `123456` | 普通用户 | 我的网咖用户中心 |

## 2. 已完成实现

### 2.1 数据库

- `sys_role` 只保留 `super_admin`、`front_desk`、`customer` 三个角色。
- `sys_user.member_id` 用于绑定普通用户账号和会员资料。
- `member001` 已绑定会员 `M0001`，余额、流水和会话均来自 MySQL 真实数据。
- 原店长、维修人员账号已软删除，维修职责并入超级管理员。
- 普通用户故障反馈写入 `device_fault`，超级管理员处理结果写入 `repair_record`。

### 2.2 超级管理员门户

- 经营看板、前台工作台、会员、设备、计费、上机、人脸、统计和系统用户。
- 新增维修维护页面，可查看普通用户提交的设备故障并完成维修。
- 完成维修后，工单状态改为已处理，关联设备恢复空闲状态，普通用户可查看处理结果。

### 2.3 前台人员门户

- 监测开机数量、当前会话、低余额会员和全部设备状态。
- 查询会员并执行真实充值，充值同步写入充值记录和账户流水。
- 选择会员、空闲机位和计费规则开始上机。
- 下机时按计费规则结算，同步更新会话、余额、消费流水和设备状态。
- 可调整计费单价和启停计费规则。
- 无权访问经营统计、系统用户和维修维护队列。

### 2.4 普通用户门户

- 我的首页：本人会员状态、余额、累计充值、累计消费、当前上机和可用机位。
- 我的账户：仅展示本人账户流水。
- 上机记录：仅展示本人历史和进行中会话。
- 机位与计费：查看实时机位状态及当前生效规则。
- 故障反馈：提交设备问题并查看本人反馈处理进度。
- 无权访问会员列表、管理设备、系统用户或其他会员数据。

## 3. 数据互通闭环

```text
前台充值 -> member_account -> 普通用户余额与流水立即变化
前台开机 -> machine_session + device_info -> 管理看板与用户当前上机同步
前台结算 -> session + consume + account_flow -> 用户消费记录与余额同步
用户报障 -> device_fault + device_info -> 管理员维修队列和设备状态同步
管理员完成维修 -> repair_record + device_info -> 用户处理进度和机位状态同步
```
