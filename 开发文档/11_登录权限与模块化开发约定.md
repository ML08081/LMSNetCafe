# 三角色登录权限与模块化开发约定

## 1. 角色定义

系统只保留三个业务角色，角色之间共用同一套会员、余额、设备、计费、会话和故障数据。

| 角色编码 | 角色名称 | 主要职责 |
| --- | --- | --- |
| `super_admin` | 超级管理员 | 全系统管理、账号权限、经营统计、设备管理和维修维护 |
| `front_desk` | 前台人员 | 门店监控、会员与余额管理、开机结算、计费管理和设备状态监控 |
| `customer` | 普通用户 | 查看本人余额与流水、本人上机记录、可用机位与计费规则、提交故障反馈 |

不再设置独立店长和维修人员角色。维修职责并入超级管理员，历史 `manager`、`repair` 账号已软删除。

## 2. 统一登录入口

三类用户统一访问 `/login`，调用：

```text
POST /api/v1/auth/login
```

登录成功后返回 Bearer Token、账号资料、角色和权限。前端根据角色自动进入对应首页：

| 角色 | 默认首页 |
| --- | --- |
| 超级管理员 | `/` 经营看板 |
| 前台人员 | `/` 门店运营工作台入口 |
| 普通用户 | `/portal` 我的网咖 |

演示账号密码均为 `123456`：

| 账号 | 角色 | 数据绑定 |
| --- | --- | --- |
| `admin` | 超级管理员 | 无会员绑定 |
| `cashier` | 前台人员 | 无会员绑定 |
| `member001` | 普通用户 | 绑定会员 `M0001` |

## 3. 功能与权限矩阵

| 功能模块 | 超级管理员 | 前台人员 | 普通用户 |
| --- | --- | --- | --- |
| 经营看板 | 管理视角 | 运营监控视角 | 不可访问 |
| 前台工作台 | 可访问 | 可访问 | 不可访问 |
| 会员与余额管理 | 可访问 | 可访问 | 仅查看本人账户 |
| 开机、续费、下机结算 | 可操作 | 可操作 | 仅查看本人会话 |
| 设备状态 | 管理与监控 | 只监控 | 查看公开机位状态 |
| 计费规则 | 可管理 | 可管理 | 只查看生效规则 |
| 人脸认证 | 可管理 | 可用于前台核验 | 当前不开放自助录入 |
| 经营统计 | 可访问 | 不可访问 | 不可访问 |
| 系统用户 | 可管理 | 不可访问 | 不可访问 |
| 维修维护 | 可处理 | 只看到设备状态 | 可提交本人故障反馈 |

## 4. 普通用户数据隔离

`sys_user.member_id` 将普通登录账号绑定到 `member_info.id`。个人门户接口必须从当前认证主体取得 `memberId`，禁止接收前端传入的任意会员编号作为查询范围。

个人门户接口：

| 接口 | 权限 | 数据范围 |
| --- | --- | --- |
| `GET /api/v1/portal/overview` | `portal:home` | 本人资料、余额、当前会话 |
| `GET /api/v1/portal/account-flows` | `portal:account` | 本人账户流水 |
| `GET /api/v1/portal/sessions` | `portal:sessions` | 本人上机记录 |
| `GET /api/v1/portal/devices` | `portal:devices` | 门店机位公开状态 |
| `GET /api/v1/portal/billing-rules` | `portal:devices` | 当前生效计费规则 |
| `GET/POST /api/v1/portal/faults` | `portal:support` | 本人反馈及新反馈 |

## 5. 前后端安全边界

前端路由和侧边栏按权限显示，用于保证正确的角色体验。后端 `SecurityConfig` 对每组 API 再次校验权限，作为数据安全边界。

- 未登录或 Token 无效返回 `401`。
- 已登录但权限不足返回 `403`。
- 普通用户即使手工请求管理接口，也不能读取会员列表、系统用户或维修队列。
- 普通用户反馈故障后，设备状态和超级管理员维修队列同步更新。

## 6. 模块化约定

后端业务按 `module/<module-name>` 划分。当前使用 `JdbcTemplate` 完成真实数据联调，后续业务扩展应逐步拆分 `controller`、`service`、`mapper`、`entity` 和 `dto`，并将充值、上机、结算等事务逻辑移入 Service 层。
