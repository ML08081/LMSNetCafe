# 网咖综合管理系统开发文档总览

## 1. 项目定位

本项目是一个面向网咖、电竞馆、机房经营场景的综合管理系统，覆盖系统管理、会员管理、人脸认证、上机计费、设备管理、数据统计和桌面桌宠。

项目优先保证以下核心闭环：

1. 管理员登录后维护会员、机位和设备信息。
2. 会员可注册、充值、查询余额和消费记录。
3. 前台可为会员选择机位、开始上机、自动计费、续费和下机结算。
4. 人脸认证用于会员身份确认和上机验证。
5. 桌面桌宠在客户端显示上机时间、当前消费、余额提醒和休息提醒。
6. 管理端可查看营业、充值、消费、上机等统计数据。

## 2. 默认技术路线

由于当前项目尚未存在代码，文档默认采用以下技术栈作为后续搭建依据：

| 层级 | 技术选型 | 说明 |
| --- | --- | --- |
| 后端服务 | Spring Boot 3、Spring Security、MyBatis-Plus | 提供业务 API、权限、计费、数据统计 |
| 数据库 | MySQL 8 | 保存会员、设备、订单、计费、认证等核心数据 |
| 缓存与任务 | Redis、Spring Scheduler | 会话缓存、计费状态缓存、定时结算检查 |
| 前端管理端 | Vue 3、Vite、TypeScript、Element Plus | 管理后台和前台收银工作台 |
| 人脸认证服务 | Python FastAPI、OpenCV、InsightFace 或 face-recognition | 独立生物识别服务，便于后续替换模型 |
| 桌面桌宠 | Electron、Vue 3、Canvas/CSS Animation | 运行在网咖客户机桌面 |
| 接口规范 | REST API、JWT、WebSocket | 常规业务用 REST，计费状态和桌宠提醒用 WebSocket |

## 4. 开发顺序建议

1. 先搭建后端、数据库、管理端基础工程。
2. 完成登录、权限、会员和设备基础数据。
3. 完成上机计费核心闭环。
4. 接入充值、消费记录和营业统计。
5. 接入人脸认证服务。
6. 开发桌宠客户端并通过 WebSocket 接收计费状态。
7. 完成联调、测试、部署和演示数据。
