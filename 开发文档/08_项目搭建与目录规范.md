## 2. 后端工程

### 2.1 技术栈

- Java 17+
- Spring Boot 3
- Spring Security
- MyBatis-Plus
- MySQL Driver
- Redis
- Knife4j 或 springdoc-openapi
- Lombok
- Maven

│   ├── system

│   ├── billing
│   ├── face
│   ├── statistics
│   └── client

    ├── scheduler

### 2.3 后端配置

建议环境变量：

```text
DB_HOST=127.0.0.1
DB_PORT=3306
DB_NAME=lms_netcafe
DB_USER=root
DB_PASSWORD=123456
REDIS_HOST=127.0.0.1
REDIS_PORT=6379
JWT_SECRET=replace-with-secret
FACE_SERVICE_URL=http://127.0.0.1:9000
```

## 6. 分支和提交规范

如后续初始化 Git，建议：

- `main`：稳定版本。
- `develop`：开发主线。
- `feature/member-management`：功能分支。
- `feature/billing-session`：功能分支。
- `fix/session-settle-repeat`：修复分支。

提交格式：

```text
feat: add member recharge api
fix: prevent duplicate session settlement
docs: add database design
chore: initialize backend project
```

## 7. 启动顺序

开发环境建议启动顺序：

1. MySQL。
2. Redis。
3. 后端 `backend`。
4. 人脸服务 `face-service`。
5. 管理端 `frontend-admin`。
6. 桌宠 `desktop-pet`。

## 8. 初始账号和演示数据

建议初始账号：

| 用户名 | 角色 | 说明 |
| --- | --- | --- |
| admin | 超级管理员 | 系统管理 |
| manager | 店长 | 业务管理 |
| cashier | 前台收银 | 开机充值 |
| repair | 维修人员 | 设备维修 |

建议演示数据：

- 20 台设备。
- 10 个会员。
- 1 条默认计费规则。
- 5 条充值记录。
- 5 条上机记录。

## 9. 后续搭建优先级

第一批创建：

1. `backend` Spring Boot 工程。
2. `frontend-admin` Vue 工程。
3. `scripts/init-db.sql` 初始化数据库脚本。

第二批创建：

1. `face-service` FastAPI 工程。
2. `desktop-pet` Electron 工程。
3. WebSocket 联调。
