# 人脸识别登录与桌宠实施报告

## 1. 实施范围

本次完成两个此前仅有工程骨架的模块：三角色统一入口的人脸识别登录，以及运行在客户机上的吾皇猫桌宠。两项功能均接入主后端和 MySQL，不再使用静态模拟数据。

## 2. 人脸识别登录

### 2.1 已实现能力

- FastAPI 人脸服务使用 OpenCV 完成人脸检测、单人校验、清晰度/亮度/尺寸质量评分。
- 录入时提取归一化 DCT 与梯度特征，压缩保存到 `face-service/data/features`，不保存登录抓拍原图。
- 支持指定用户 1:1 验证和已录入用户 1:N 识别。
- `face_profile` 新增 `sys_user_id`，超级管理员、前台人员和普通用户都可建立独立人脸档案。
- 管理端人脸工作台支持选择用户、首次录入、重新录入、现场验证、删除档案和查看日志。
- 统一登录页提供“账号密码 / 人脸识别”两种模式，识别成功后仍由主后端签发相同的登录令牌，角色路由规则保持一致。
- 图片限制为 5MB；无脸、多脸、低质量、未录入、用户停用和服务离线均返回明确错误。

### 2.2 安全边界

浏览器只调用 Java 主后端，不能提交用户编号伪造识别结果。人脸服务只返回候选标识和相似度，主后端会再次校验数据库中的启用用户及有效档案。

当前算法是适合本机演示和课程设计验收的 OpenCV 基线实现。生产环境上线前必须增加活体检测、专业人脸嵌入模型、阈值校准、特征加密、访问审计和数据注销流程。

## 3. 吾皇猫桌宠

### 3.1 视觉与窗口

- 使用用户提供的吾皇猫图片作为参考，通过图像编辑生成无水印素材，并进一步处理为真实 alpha 透明 PNG。
- Electron 窗口透明、无边框、默认置顶、可拖动，关闭窗口时驻留托盘。
- 吾皇猫具备待机呼吸动画，低余额状态会切换提醒动画。
- 点击桌宠可展开上机详情，托盘支持显示、隐藏、重新连接和退出。

当前修复后的素材路径：`desktop-pet/public/wuhuang-cat-v2.png`。

### 3.2 数据闭环

- 桌宠默认连接 `http://127.0.0.1:8080`，默认设备为 `PC-A01`，可在设置中修改。
- 客户机先按设备编号注册，后端签发随机设备令牌。
- 桌宠每 20 秒上报心跳，每 5 秒拉取当前会话快照，断线后每 10 秒自动重连。
- 会话数据包含会员、开始时间、已用时长、当前费用、余额、低余额阈值和设备状态。
- 桌宠只拥有注册、心跳和只读会话权限，不能充值、结算或修改会员数据。
- 连续上机达到 2 小时触发休息提醒；余额不足触发醒目提示。

## 4. 新增接口

| 接口 | 用途 | 访问控制 |
| --- | --- | --- |
| `POST /api/v1/auth/face-login` | 从统一登录页进行 1:N 人脸登录 | 公开，但由后端校验档案和用户状态 |
| `GET /api/v1/faces/candidates` | 查询可录入的三角色用户 | `face:manage` |
| `POST /api/v1/faces/enroll` | 录入或更新用户人脸 | `face:manage` |
| `POST /api/v1/faces/verify` | 对指定用户进行现场验证 | `face:manage` |
| `DELETE /api/v1/faces/{userId}` | 停用并删除特征 | `face:manage` |
| `POST /api/v1/clients/register` | 绑定已存在的客户机设备 | 已知设备编号 |
| `POST /api/v1/clients/{deviceCode}/heartbeat` | 更新客户机在线状态 | `X-Client-Token` |
| `GET /api/v1/clients/{deviceCode}/session` | 获取只读实时计费快照 | `X-Client-Token` |

## 5. 验证结果

- MySQL 初始化脚本重复执行成功，人脸档案表迁移完成，模拟特征记录已清理。
- 后端 `mvn test` 通过，目标兼容 Java 17，运行使用 `E:\DevTools` 下的 JDK 21 和 Maven。
- 管理端 `npm run build` 通过。
- 桌宠 Vue、Electron 主进程和预加载脚本完整构建通过，Electron 二进制可用。
- 后端与人脸服务健康检查均为 `UP`。
- `PC-A01` 注册、令牌校验、心跳和真实运行中会话查询通过；无效令牌返回 401 及中文原因。
- 非人脸图片被 OpenCV 拒绝，统一登录接口返回业务码 `40101` 和具体重拍提示，证明识别接口未使用固定成功模拟值。
