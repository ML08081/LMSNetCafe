# 前端页面与交互设计

## 1. 前端定位

前端包含两个主要界面：

1. 管理后台：给管理员、店长、维修人员使用。
2. 前台工作台：给前台收银高频处理会员、充值、开机和结算。

桌宠属于独立 Electron 客户端，详细见 `07_桌面桌宠模块设计.md`。

## 2. 路由规划

| 路由 | 页面 | 说明 |
| --- | --- | --- |
| `/login` | 登录页 | 用户登录 |
| `/dashboard` | 首页看板 | 今日营业、在线人数、设备状态 |
| `/workbench` | 前台工作台 | 会员查询、开机、续费、下机 |
| `/members` | 会员列表 | 查询、注册、编辑、冻结 |
| `/members/:id` | 会员详情 | 账户、充值、消费、上机记录 |
| `/devices` | 设备管理 | 机位列表、状态、故障 |
| `/devices/map` | 机位视图 | 按区域展示机位状态 |
| `/sessions` | 上机记录 | 历史记录和当前会话 |
| `/billing/rules` | 计费规则 | 设置每小时价格和提醒规则 |
| `/faces` | 人脸认证 | 录入、验证日志 |
| `/statistics` | 数据统计 | 营业、充值、消费报表 |
| `/system/users` | 用户管理 | 后台账号 |
| `/system/roles` | 角色权限 | 权限配置 |

## 3. 页面设计

### 3.1 登录页

- 居中登录表单。
- 字段：用户名、密码。
- 状态：登录中、账号停用、密码错误、网络异常。
- 登录成功后跳转到 `/dashboard`。

### 3.2 首页看板

核心信息：

- 今日营业额。
- 今日充值金额。
- 当前在线人数。
- 机位使用率。
- 低余额提醒。
- 故障设备数量。

交互：

- 点击在线人数进入当前上机会话列表。
- 点击故障设备进入设备故障列表。
- 点击营业额进入营业统计页面。

### 3.3 前台工作台

布局建议：

- 左侧：会员搜索和会员账户信息。
- 中间：机位选择视图。
- 右侧：当前操作面板和上机会话摘要。

关键操作：

- 搜索会员：手机号、会员编号、姓名。
- 注册会员：弹窗录入。
- 充值：弹窗输入金额和支付方式。
- 开始上机：选择会员、机位、计费规则。
- 续费：快速进入会员充值。
- 下机结算：显示最终费用并确认。

必要状态：

- 会员未选择。
- 会员被冻结。
- 余额不足。
- 设备非空闲。
- 人脸验证未通过。
- 结算中防重复提交。

### 3.4 会员管理

列表字段：

- 会员编号、姓名、手机号、等级、余额、状态、注册时间。

操作：

- 查看详情。
- 编辑资料。
- 充值。
- 冻结/解冻。
- 人脸录入状态。

### 3.5 设备管理

展示方式：

- 表格列表：适合批量管理。
- 机位地图：适合前台开机。

设备状态颜色建议：

| 状态 | 展示 |
| --- | --- |
| 空闲 | 绿色 |
| 使用中 | 蓝色 |
| 维护中 | 橙色 |
| 故障 | 红色 |
| 停用 | 灰色 |

### 3.6 上机记录

筛选条件：

- 时间范围。
- 会员。
- 设备编号。
- 会话状态。
- 操作员。

列表字段：

- 会话编号、会员、机位、开始时间、结束时间、时长、费用、状态。

### 3.7 人脸认证页面

功能：

- 查看会员人脸录入状态。
- 调用摄像头录入人脸。
- 展示识别质量评分。
- 查看验证日志。

交互要求：

- 录入前需要选择会员。
- 未检测到人脸时明确提示。
- 多人入镜时拒绝录入。
- 录入成功后显示状态，不展示敏感原图作为默认列表内容。

## 5. 状态管理

建议使用 Pinia：

- `authStore`：token、用户信息、权限。
- `memberStore`：当前选中的会员和账户信息。
- `deviceStore`：设备列表和机位状态。
- `sessionStore`：当前上机会话、WebSocket 状态。
- `systemStore`：字典、菜单、全局配置。

## 6. 前端请求规范

- 使用统一 `request` 封装 Axios。
- 请求自动携带 JWT。
- `401` 自动跳转登录页。
- 后端业务错误使用消息提示。
- 表单提交按钮必须有 loading 状态。
- 高风险操作二次确认，例如冻结会员、强制下机。

## 7. 可用性要求

- 前台工作台操作路径要短，支持键盘回车搜索会员。
- 结算、充值、开机操作必须防止重复点击。
- 余额不足、人脸失败、设备故障等异常要给出明确原因。
- 表格页保留筛选条件，返回时不丢失上下文。
