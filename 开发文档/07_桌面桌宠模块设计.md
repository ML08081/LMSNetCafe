# 桌面桌宠模块设计

## 1. 模块目标

桌面桌宠运行在网咖客户机上，面向正在上机的会员展示轻量提醒信息：

- 当前上机时长。
- 当前累计消费。
- 当前账户余额。
- 低余额提醒。
- 长时间上机休息提醒。

桌宠不直接计算最终费用，所有计费结果以后端为准。

## 2. 技术方案

建议使用 Electron + Vue 3：

- Electron 提供桌面窗口、置顶、透明背景和托盘能力。
- Vue 3 提供状态驱动 UI。
- WebSocket 接收后端实时推送。
- 本地配置保存设备编号和服务地址。

## 3. 客户端能力

| 能力 | 说明 |
| --- | --- |
| 桌面动画 | 默认显示一个轻量动画形象 |
| 拖拽移动 | 用户可拖动位置 |
| 窗口置顶 | 默认置顶但不打断游戏或操作 |
| 信息气泡 | 展示时长、消费、余额 |
| 低余额提醒 | 余额低于阈值时提醒 |
| 休息提醒 | 连续上机达到阈值时提醒 |
| 心跳上报 | 定时告诉后端客户机在线 |
| 托盘菜单 | 显示、隐藏、重新连接、退出 |

## 4. 运行状态

| 状态 | 显示内容 |
| --- | --- |
| 未绑定设备 | 显示配置入口 |
| 已连接无会话 | 显示待机动画 |
| 上机中 | 显示时长、消费、余额 |
| 低余额 | 显示提醒气泡 |
| 连接断开 | 显示离线标识并重连 |
| 会话结束 | 清空会话信息，回到待机 |

## 5. 通信设计

### 5.1 启动流程

1. 读取本地配置 `deviceCode` 和 `serverUrl`。
2. 调用 `/api/v1/clients/register` 注册客户机。
3. 连接 `/ws/client/{deviceCode}`。
4. 调用 `/api/v1/clients/{deviceCode}/session` 拉取当前会话。
5. 开始心跳上报。

### 5.2 WebSocket 消息

```json
{
  "type": "SESSION_UPDATED",
  "timestamp": "2026-08-31T08:00:00+08:00",
  "data": {
    "sessionId": 1001,
    "memberName": "张三",
    "startedAt": "2026-08-31T07:30:00+08:00",
    "durationMinutes": 30,
    "currentAmount": 5.00,
    "balance": 45.00
  }
}
```

## 6. UI 设计

桌宠窗口建议：

- 默认宽度 220px，高度 260px。
- 透明背景。
- 下方显示小型状态条。
- 鼠标悬停时展示详细信息。
- 低余额时出现醒目但不遮挡操作的提醒气泡。

信息内容：

```text
已上机 01:28
消费 14.50 元
余额 35.50 元
```

## 7. 提醒规则

| 提醒 | 触发条件 | 频率 |
| --- | --- | --- |
| 低余额 | 余额低于计费规则阈值 | 每 5 分钟最多一次 |
| 即将不足 | 预计余额只能使用 10 分钟 | 每次状态变化最多一次 |
| 休息提醒 | 连续上机 2 小时 | 每 1 小时一次 |
| 连接异常 | WebSocket 断开超过 30 秒 | 状态栏持续显示 |

## 8. 本地配置

建议配置文件：

```json
{
  "serverUrl": "http://127.0.0.1:8080",
  "deviceCode": "PC-001",
  "autoStart": true,
  "alwaysOnTop": true
}
```

## 9. 安全要求

- 桌宠只保存设备编号，不保存会员敏感信息。
- WebSocket 连接应带设备访问令牌或签名。
- 桌宠不能直接修改余额、结算或会员状态。
- 管理员退出桌宠需要权限或本机管理密码。

## 10. 开发阶段策略

第一阶段：

- 实现静态桌宠窗口。
- 支持配置设备编号。
- 连接 WebSocket。
- 显示后端推送的模拟会话状态。

第二阶段：

- 增加动画状态。
- 增加心跳和断线重连。
- 增加提醒节流。
- 打包为 Windows 安装程序。
